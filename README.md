# Standoff 3 — PC Edition

Шутер от первого лица в духе Standoff 2 / Counter-Strike с ботами. Работает в браузере Chrome/Edge, ничего устанавливать не нужно.

## Запуск
1. Дважды кликните **Standoff3.bat** — игра откроется в отдельном окне Chrome (или Edge) на весь экран.
2. Либо просто откройте `index.html` в Chrome/Edge.
3. В меню: «Играть» → выберите режим, карту, команду, число и сложность ботов → «Начать матч».
4. Кликните по экрану, чтобы захватить мышь. Esc — пауза, F11 — полный экран.

## Режимы
- **Разминирование** — классика: T ставят бомбу на A/B, CT защищают. Раунды, экономика ($), покупка оружия (B), смена сторон.
- **Командный бой** — команда на команду с возрождением до лимита убийств.
- **Каждый за себя** — все против всех.
- **Гонка вооружений** — каждое убийство даёт новое оружие, последний уровень — нож.

## Карты
Sandstone (пустыня, лонг/мид/тоннели), Rust (промзона, контейнеры), Province (старый город), Arena (для режимов с возрождением).

## Управление
WASD — движение, мышь — обзор, ЛКМ — огонь, ПКМ — прицел/удар ножом, Space — прыжок, Ctrl — присед, Shift — тихий шаг,
R — перезарядка, 1–5 — оружие, Q — предыдущее, E — обезвредить/подобрать, B — магазин, G — выбросить, F — осмотр, Tab — таблица, Z — радио.

## Технологии
Three.js r158 (lib/three.min.js). Все текстуры, модели и звуки генерируются процедурно в самой игре (Canvas + Web Audio).
Настройки и статистика сохраняются в localStorage браузера.
