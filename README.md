# Standoff 3 — PC Edition

Шутер от первого лица в духе Standoff 2 / Counter-Strike с ботами. Работает в браузере Chrome/Edge, ничего устанавливать не нужно.

## Запуск
1. Дважды кликните **Standoff3.bat** — игра откроется в отдельном окне Chrome (или Edge) на весь экран.
2. Либо просто откройте `index.html` в Chrome/Edge.
3. В меню: «Играть» → выберите режим, карту, команду, число и сложность ботов → «Начать матч».
4. Кликните по экрану, чтобы захватить мышь. Esc — пауза, F11 — полный экран.

## Режимы
- **Разминирование** — классика: T ставят бомбу на A/B, CT защищают. Раунды, экономика ($), покупка оружия (B), смена сторон.
- **Командный бой** — команда на команду с возрождением до лимита убийств.
- **Каждый за себя** — все против всех.
- **Гонка вооружений** — каждое убийство даёт новое оружие, последний уровень — нож.

## Карты
Sandstone (пустыня, лонг/мид/тоннели), Rust (промзона, контейнеры), Province (старый город), Arena (для режимов с возрождением).

## Управление
WASD — движение, мышь — обзор, ЛКМ — огонь, ПКМ — прицел/удар ножом, Space — прыжок, Ctrl — присед, Shift — тихий шаг,
R — перезарядка, 1–5 — оружие, Q — предыдущее, E — обезвредить/подобрать, B — магазин, G — выбросить, F — осмотр, Tab — таблица, Z — радио.

## Игра по сети (LAN)
Один из игроков — хост, остальные подключаются к нему по локальной сети. Нужен Python (уже есть на компьютере хоста).

**Хост:**
1. Дважды кликните **Standoff3-Host.bat** — откроются два окна-сервера и покажут ваш IP-адрес в сети. Не закрывайте эти окна.
2. В игре откроется меню — нажмите «🌐 Игра по сети» → «Создать игру (хост)» → «Подключиться как хост».
3. Выберите режим, карту, ботов, свою команду, дождитесь в списке остальных игроков и нажмите «НАЧАТЬ ИГРУ ДЛЯ ВСЕХ».

**Остальные игроки:**
1. Откройте игру любым способом (свой `Standoff3.bat`, или в браузере адрес `http://IP_ХОСТА:8765`).
2. «🌐 Игра по сети» → «Присоединиться» → впишите ник и адрес `ws://IP_ХОСТА:8766` (IP хост сообщит из своего окна сервера) → «Подключиться».
3. Дождитесь, пока хост начнёт матч.

Хост считает всю игру (физику, попадания, ботов, раунды) — так честнее и надёжнее по сети; у остальных клиент лёгкий.
**Ограничения этой версии:** только локальная сеть, без матчмейкинга; подключиться можно только до старта матча (не на ходу);
брошенное на землю оружие не синхронизируется между игроками; голосового чата нет.

## Кейсы и скины
Пункт меню «🎁 Кейсы и скины». За каждый завершённый матч начисляется золото (150 + 8 за убийство + 4 за хедшот + 120 за победу);
на старте выдаётся 2000 золота. Пять кейсов (новичка, штурмовой, снайперский, ножевой, золотой), 300+ скинов шести редкостей:
Обычный → Необычный → Редкий → Эпический → Легендарный → Арканный. Открытие — рулетка как в CS; выпавший скин можно надеть или продать за золото.
Надетые скины видны от первого лица, на моделях персонажей, на выброшенном оружии и другим игрокам по сети (боты тоже ходят со случайными скинами).
Инвентарь хранится в localStorage браузера.

- **3.1.0** — мультиплеер по локальной сети, никнеймы, исправлена анимация ботов.

## Технологии
Three.js r158 (lib/three.min.js). Все текстуры, модели, скины и звуки генерируются процедурно в самой игре (Canvas + Web Audio).
Сетевой релей-сервер (`server.py`) — чистый Python без внешних зависимостей (свой WebSocket-хендшейк и фреймы).
Настройки, статистика и инвентарь скинов сохраняются в localStorage браузера.
